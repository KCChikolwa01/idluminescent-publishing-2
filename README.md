# ID Luminescent Publishing website

This repository contains the extracted static website files for ID Luminescent Publishing.

## Cloudflare Pages

When connecting this repository to Cloudflare Pages, use the root directory (`/`) as the project root. For this existing static HTML site, leave the build command empty and set the output directory to `.`.

Do not upload the ZIP file into the repository. Upload the contents of this folder so that `index.html` is at the repository root.

The existing live Cloudflare deployment should remain unchanged until the GitHub-connected deployment has been tested.
